# تسليم خلود — نموذج تكامل قابل للتجربة

## التشغيل على Windows (بدون Docker أو قاعدة بيانات أو إنترنت)
1. ثبتي Python 3.10 أو أحدث من المصدر الرسمي إذا لم يكن مثبتًا، وفعّلي Add Python to PATH.
2. افتحي المجلد `kholoud_integration_demo`.
3. اضغطي مرتين على `RUN_WINDOWS.bat` واتركي النافذة السوداء مفتوحة.
4. افتحي `http://localhost:8765` في المتصفح.
5. اضغطي **إرسال طالب جديد** → Succeeded، ثم **إعادة نفس الرسالة** → DuplicateIgnored، ثم **إرسال تحديث قديم** → StaleIgnored، ثم **إرسال تحديث أحدث** → Succeeded، ثم **اختبار مؤسسة خاطئة** → SEC-403، ثم **اختبار بيانات ناقصة** → FailedValidation.
6. لاحظي أن عدد الطلاب يبقى 1، مع تغيّر الاسم عند التحديث الصحيح، وظهور Security Event عند محاولة الكتابة خارج المؤسسة.
7. شغّلي `TEST_WINDOWS.bat`؛ النتيجة المتوقعة `Ran 8 tests` ثم `OK`.
8. لإيقاف الخادم اضغطي Ctrl+C في نافذته.

## المهام الرسمية
- INT-000: واجهة محاكاة إرسال الطالب، تعمل داخل صفحة العرض المستقلة.
- INT-001: تهيئة sourceSystem مع institutionId وcontractVersion واختبار اتصال محاكى؛ ليست عملية OAuth/mTLS فعلية.
- INT-002: envelope يحتوي sourceSystem/messageId/externalId/eventTime/payload مع receivedAt/correlationId في السجل.
- INT-003: هوية الرسالة (sourceSystem,messageId) مستقلة عن هوية الطالب (sourceSystem,externalId).
- INT-004: تجاهل التحديث الأقدم مع StaleIgnored.
- INT-006: راجعي `LEGACY_BATCH_INTEGRATION.md`.
- HRD-003: راجعي `PERFORMANCE_VERIFICATION.md`.

## حدود التسليم المهمة
هذا نموذج **مستقل قابل للتشغيل** لتعلم/عرض جزء خلود، أُضيف دون تعديل بقية وحدات المستودع. لا يحقق وحده تكامل NestJS/قاعدة بيانات الفريق ولا يثبت جاهزية End-to-End. التخزين في الذاكرة، لذا تضيع البيانات عند إغلاق الخادم. لا يوجد OAuth2/mTLS حقيقي ولا Rate Limit ولا Replay Window ولا Audit دائم ولا واجهة صلاحيات مؤسسية؛ لا تستخدميه كخدمة منشورة أو تدّعي اكتمال Definition of Done للمشروع. يتطلب دمجه مع API المركزية مراجعة العقد وقرارات الفريق والاختبارات الأمنية.

## ما تقولينه في العرض
"أنا خلود، مسؤولة عن Integration Core وMock University. أرسل طالبًا من نظام الجامعة إلى طبقة التكامل. الرسالة تحتوي هوية المصدر والرسالة والطالب ووقت الحدث. النظام يتحقق من المؤسسة والبيانات، يمنع التكرار ويمنع التحديثات القديمة. أعرض النتائج في Integration Monitor. هذا النموذج إثبات فكرة وليس نظامًا وطنيًا كاملًا."
