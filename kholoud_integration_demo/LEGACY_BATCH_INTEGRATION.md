# TASK-INT-006 — Legacy Batch/File Integration (Documentation Only)

Legacy institutions may exchange versioned CSV/JSON files through a configured adapter. The conceptual sequence is: register the source and institution scope; receive a file via an approved channel; validate schema and file limits; assign message identities per record; transform to the canonical envelope; enforce institution scope; process idempotently; report successes, duplicates, stale records, validation failures and quarantined records; retain correlation, receipt timestamp and audit metadata. Failed records should be isolated for review/retry, not silently discarded. This is a design description, not an implemented file importer. Contract compatibility and the 90-day breaking-change policy remain governed by the Baseline (NFR-024). No production credential storage or actual batch upload is provided.
