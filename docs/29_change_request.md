# Change Request Process

Source: Analysis Baseline — Section 21.

## CR Form
| الحقل | المحتوى المطلوب |
| --- | --- |
| CR-ID | معرف فريد. |
| Requested By | الطالب/المشرف/صاحب المصلحة. |
| Change | وصف التغيير. |
| Reason | لماذا؟ |
| Affected Requirements | FR/NFR/BR/UC المتأثرة. |
| Data Impact | كيانات/حقول/مصدر حقيقة. |
| Integration Impact | واجهات/إصدارات/أنظمة. |
| Design/Test Impact | المكونات وحالات الاختبار. |
| Decision | Approved/Rejected/Deferred. |
| Baseline Version | الإصدار الجديد عند الاعتماد. |

## Rule
بعد اعتماد التحليل، أي تغيير سلوكي/بياناتي/نطاقي لا يعالج كتعديل كود صامت.
يجب فتح Change Request وتقييم أثره على FR/BR/NFR/Data/API/Test.
