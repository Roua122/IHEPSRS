# Prototype Acceptance Gate

يعتبر الـPrototype جاهزًا للعرض عندما تتحقق جميع النقاط التالية:

- [ ] Login يعمل.
- [ ] RBAC يمنع إجراء واحد غير مصرح على الأقل ويتيح الإجراء الصحيح.
- [ ] Mock University ترسل Student إلى IHEPSRS عبر Integration boundary.
- [ ] Integration Monitor يعرض نجاح الرسالة وحالة خطأ/تكرار واحدة على الأقل.
- [ ] Postgraduate Application تعمل حتى Accepted.
- [ ] Enrollment ينشأ بعد القبول وفق القيود.
- [ ] Thesis lifecycle تعمل حتى Final Approval.
- [ ] Supervisor assignment مطبق.
- [ ] Proposal workflow مطبق.
- [ ] Defense outcome مطبق.
- [ ] Corrections flow مطبق أو تم اختيار Pass مباشر للعرض مع بقاء corrections قابلة للاختبار.
- [ ] Publication مرتبطة بباحث/مؤلف.
- [ ] Dashboard يعرض مؤشرات من البيانات الفعلية.
- [ ] Audit يعرض عمليات حساسة من السيناريو.
- [ ] لا توجد Secrets داخل Git.
- [ ] جميع Tasks المصنفة `MUST` للعرض مكتملة أو موثق سبب استثنائي معتمد.
- [ ] Demo scenario يعمل بدون تعديل يدوي مباشر لقاعدة البيانات.
