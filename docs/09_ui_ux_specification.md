# UI / UX Specification — Baseline Constraints + Prototype Design

## Source constraints
- Arabic RTL + English: NFR-019.
- WCAG 2.2 AA: NFR-019 / NFR-035.
- Understandable errors: NFR-018 and Section 16.
- Scope-aware access: BR-027 / BR-035.
- Sensitive values must be masked: NFR-025.

## Required page states
كل صفحة بيانات يجب أن تصمم لحالات:
- Loading
- Empty
- Success
- Validation error
- Permission denied
- Record/state conflict
- Integration pending/failure where relevant

## Accessibility
Keyboard navigation, visible focus, labels, contrast, screen-reader semantics,
accessible errors/tables, no color-only status meaning.

## Visual design
الألوان، Design System، component library والتفاصيل الجمالية تبقى Design Decisions.
