# Data Model Reference

هذا الملف هو Index فقط إلى أن يتم اعتماد ERD.

## Analysis-derived constraints
- Person هو الكيان الأساسي للشخص.
- Effective dating للكيانات المرجعية ذات الصلة.
- Historical/versioned data حيث يفرض الـBaseline.
- Referential integrity للوثائق يجب ألا تترك Orphans.
- Field-level Source of Truth يحكم التعديل.
