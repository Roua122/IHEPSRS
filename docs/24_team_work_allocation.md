## Shared responsibilities
الجميع مسؤول عن:
- قراءة الـBaseline والـPrototype Scope قبل التنفيذ.
- الالتزام بـGit workflow.
- كتابة/تحديث اختبارات مهامه.
- مراجعة Pull Request لعضو آخر.
- عدم تغيير Business Rule أو State أو Source of Truth بصمت.
- تحديث Task/TODO بعد الدمج.

## Cross-review pairing
- رؤى محمد ↔ خلود مهيب
- مرام وديع ↔ سمية خالد
- رهف عادل ↔ دعاء عبد الواحد
- أمة الرحمن فواد تراجع تكامل السيناريو النهائي وتشارك في المراجعات الحرجة.

## Important
عدد المهام ليس مؤشر الصعوبة الوحيد:
- Integration Core أقل عددًا لكنه من أصعب أجزاء المشروع.
- Thesis Critical Workflow أقل عددًا لكنه يحتوي State Transitions حساسة.
- Reporting/Release يصبح حمله أكبر قرب موعد العرض.
